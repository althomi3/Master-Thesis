# Master Thesis: Recreation for All - Improving Access to Nature-Based Stays for Public Transport Users through Platform Design

- This repository contains research material, data, and reports other researchers and practitioners can use.
- If you use the research material, please quote the materials properly.
- To access research materials such as the user test guideline or the data tables with the cleaned qualitative and quantitative data, use the folder research_material. Other folders, such as the src folder, contain data to run the Jupyter Notebook for the quantitative data analysis with Python. The human-readable script with the data analysis results can be accessed through the file main.ipynb.

The original Figma files exceed the Github upload. They can be requested through: alischa.thomas@outlook.de
Figma files include:
1. A component set and framework to analyze mixed data
2. The results from the data analysis of the Master's thesis
3. An interactive prototype to explore reachable accommodations for short trips
